# Strava API logos

Official "Powered by Strava" artwork, downloaded unmodified from
<https://developers.strava.com/downloads/1.2-Strava-API-Logos.zip>
(linked from <https://developers.strava.com/guidelines/>).

These files are Strava trademarks, vendored here so attribution never depends
on a third-party CDN staying up. Per Strava's brand guidelines they must not be
modified, altered or animated, must never be used as this application's own
icon, and must not appear more prominently than the bot's own branding.

| File | Used by |
|------|---------|
| `api_logo_pwrdBy_strava_horiz_orange.png` | OAuth result pages (`src/server/webhook.js`) and route maps (`src/maps/MapRenderer.js`) |
| `api_logo_pwrdBy_strava_horiz_orange.svg` | Vector source, kept for future use |

Replace them only by re-downloading the official kit.
